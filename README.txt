love that - profile display update

Replace your existing src/main.jsx with the included main.jsx.

Changes:
- Saved primary profile photo is now shown in the circular avatar above the user's name.
- If there is no photo, the user's initial is shown instead.
- Profile details are collapsed by default behind an "Edit profile information" drop-down button.
- Name, age, location, job, height, body type, marital status, religion, bio, interests, hobbies and dating preferences remain available inside the drop-down.
- Profile photos remain visible without opening the details section.
- Saved profile photos are displayed in a smaller two-column grid instead of one huge image.
- Bio video and Shorts upload sections remain visible without opening profile details.

This update uses the existing profile-photo-url function and profile_photos table already used by the project.
